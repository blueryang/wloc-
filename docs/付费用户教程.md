# WLOC 虚拟定位 · 用户配置教程

> 预计用时 10 分钟，跟着一步步来，一次搞定。
> 全程在 iPhone 上操作，不需要电脑、不需要越狱。

---

## 0. 开通后你会收到

客服会发你一个**专属链接**，长这样：

```
https://wloc-spoofer.unlocknazi.workers.dev/?token=wloc_xxxx...
```

**这个链接是你的私人钥匙，不要转发给别人。** 下面所有步骤都用它。

---

## 1. 安装 Stash

1. 打开 App Store，搜索 **Stash**，购买并安装（一次性付费，约 ¥20）
2. 打开 Stash，按提示允许添加 VPN 配置（点「允许」并验证面容/密码）

---

## 2. 导入 WLOC 模块

1. 复制下面的订阅链接：
   ```
   https://cdn.jsdelivr.net/gh/blueryang/wloc-@main/modules/wloc.stoverride
   ```
2. 打开 Stash → **设置** → **覆写** → 右上角 **+** → **从 URL 下载**
3. 粘贴链接，点确定，等待下载完成
4. 回到 Stash 首页，确认覆写已勾选启用

---

## 3. 安装证书并信任（最关键的一步）

1. Stash → **设置** → **证书** → **生成新的 CA 证书**（如果已有可跳过）
2. 点 **安装证书**，按提示去「设置」安装描述文件：
   - 打开 iPhone **设置** → **通用** → **VPN 与设备管理** → 点击 Stash 证书 → **安装**
3. 回到 **设置** → **通用** → **关于本机** → **证书信任设置** → 打开 Stash 证书的开关（变绿即成功）

> ⚠️ 第 3 步最容易漏：装了证书但没开信任，等于没装。

---

## 4. 开启 MITM

1. Stash → **设置** → **HTTPS 解密（MITM）** → 打开总开关
2. 确认主机名列表里有：
   - `gs-loc.apple.com`
   - `gs-loc-cn.apple.com`
   （导入覆写后会自动带上，没有就手动加）

---

## 5. 启动并修改定位

1. 回到 Stash 首页，打开右上角总开关（VPN 图标亮起）
2. 用 Safari 打开你的**专属链接**
3. 在地图上点一个位置 → 点 **「储存到设备」**
4. 看到「✓ 已储存」就成功了

---

## 6. 验证

1. 打开 Apple 地图 / 高德，点定位按钮，看蓝点是不是在你选的位置
2. 打开微信 → 发个位置给朋友，确认显示的是虚拟位置

如果位置没变，看下面的排查。

---

## 7. （可选）快捷指令一键切换

想更快切换，可以建两个快捷指令：

- **设置位置**：获取「地图 App 分享链接」→ 用「获取 URL 内容」请求：
  ```
  https://wloc-spoofer.unlocknazi.workers.dev/api/parse?token=你的token&url=分享链接
  ```
  （token 就是你专属链接 `?token=` 后面的那串）
- **恢复真实定位**：请求 `https://gs-loc.apple.com/wloc-settings/save?action=clear`
  （⚠️ 这一步必须在 Stash 开启状态下执行）

---

## 8. 常见问题

| 现象 | 排查 |
|---|---|
| 点「储存到设备」报错 | Stash 总开关开了吗？MITM 开了吗？证书信任了吗？三步逐一检查 |
| 专属链接打不开/403 | 链接复制全了吗？token 过期了吗？问客服 |
| 地图 App 位置没变 | 先把地图 App 彻底划掉重开；确认 Stash 开关是开的 |
| 换了位置又跳回去 | iPhone 偶尔会用 GPS 纠正，等几秒或重开 App；确定「储存到设备」显示成功了 |
| iOS 大版本升级后失效 | 先别升级，问客服确认兼容性 |

---

## 9. 注意事项

- 专属链接不要外传，一人一链
- 长期不用时，在专属页面点「清除数据」恢复真实定位，再关掉 Stash
- 遇到搞不定的，直接找客服，别自己乱改配置
